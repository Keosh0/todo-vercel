# TodoList — деплой на Vercel

React-приложение «Мой список дел» (Vite), развёрнутое на Vercel с автоматическим деплоем из GitHub.
Основано на клиенте TodoList из задания по Express.js.

## Запуск локально

Требуется Node.js 20+.

```bash
npm install
npm run dev      # режим разработки, http://localhost:5173
npm run build    # продакшн-сборка в папку dist
npm run preview  # просмотр собранной версии
```

## Переменные окружения

Секреты не хранятся в репозитории: `.env` и `.env.local` исключены в `.gitignore`.
Для локальной работы скопируйте `.env.example` в `.env.local` и подставьте значения.

| Переменная | Где используется | Назначение |
|---|---|---|
| `API_KEY` | серверная функция `api/status.js` | секретный ключ; на Vercel хранится как Secret и не попадает в код страницы |
| `VITE_API_URL` | клиент | адрес Express API (необязательно); если не задан, задачи хранятся в `localStorage` |
| `VITE_API_KEY` | клиент | ключ для заголовка `x-api-key` при работе с Express API (необязательно) |

Переменные с префиксом `VITE_` встраиваются в сборку и видны в браузере, поэтому настоящие секреты
хранятся без этого префикса и читаются только на сервере. На Vercel переменные задаются в **Settings → Environment Variables**.

Функция `GET /api/status` возвращает окружение деплоя, ветку и признак того, что `API_KEY` задан (без значения).

## Оптимизация сборки

- **Ленивая загрузка** (`React.lazy` + `Suspense`): компонент `TaskList` вынесен в отдельный файл и загружается по требованию.
- **Отдельный файл библиотек** (`manualChunks` в `vite.config.js`): React и ReactDOM собираются в `vendor-*.js`.
  Этот файл меняется редко и берётся из кэша браузера, а после очередного деплоя заново скачивается только код приложения.

| Сборка | Основной JS-файл |
|---|---|
| до оптимизации | `index-*.js` — 227,80 кБ (gzip 71,09 кБ), весь код в одном файле |
| после | `index-*.js` — 4,85 кБ (gzip 2,27 кБ) + `vendor-*.js` 223,08 кБ (кэшируется) + `TaskList-*.js` 1,34 кБ |

## Деплой на Vercel

Настройки сборки (также зафиксированы в `vercel.json`):

- Framework Preset — **Vite**
- Build Command — `npm run build`
- Output Directory — `dist`

CI/CD: каждый push в `main` обновляет продакшн-версию, push в любую другую ветку создаёт превью-деплой с отдельной ссылкой.
Внизу страницы приложение показывает окружение (`production` / `preview`) и ветку, из которой собрано.
